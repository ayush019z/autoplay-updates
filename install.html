ANDROID INSTALL GUIDE

Install AutoPlay

Follow these steps on your Android phone or tablet. You stay in control of whether to install the app.

Download APK ↗Need help?

1Download the APK

Tap Download APK above. If the Releases page opens, download the file named Autoplay.apk. Wait for the download to finish.

2Open the downloaded file

Open your browser's Downloads list or the My Files / Files app, go to Downloads, and tap Autoplay.apk.

3Allow this source if Android asks

If you see a message that your phone can't install apps from this source, tap Settings on that prompt and enable Allow from this source for the browser or file manager you used. Return to the installer. The wording can vary by Android version.

Only enable this for a source you trust. You can turn it off again after installing.

4Install and open

Review the Android installer prompt and tap Install. When it finishes, tap Open or find AutoPlay in your apps list.

5Follow in-app setup

Read the app's setup and permission explanations carefully. Grant only permissions you understand and want to use for the app's stated features.

Play Protect settings reference

Play Protect notice: Play Protect scans apps and may warn you about apps installed outside Google Play. The settings screen sometimes shows scanning as temporarily paused, with automatic re-enabling scheduled. This is not a required installation step. We recommend keeping Play Protect on. If it blocks AutoPlay, do not disable protection just to proceed; verify the APK and contact support if you are unsure.

Common issues

  • Can't find the APK? Check the browser's Downloads list or your device's Downloads folder.
  • App not installed? Check that the download completed and that your device has enough free storage. Avoid uninstalling an existing version unless you understand the impact on its data.
  • Update or signature error? Don't uninstall the current app or install a different APK from an unofficial source. Contact support with the exact error message.
